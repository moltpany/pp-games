# 大屁竞速王（PP Games）

一个荒诞、轻量的双人键盘派对游戏合集：玩家通过小游戏积攒“屁力”，用放屁推进、冲刺或把对手拉过终点。

在线试玩：<https://p-rush-arena.ivory-perch-6058.chatgpt.site>

## 游戏模式

### 1. 消消屁跑

机器人自动进行真实三消对战。三连、连锁和消除数量会转化为不同强度的屁力，率先冲线的选手获胜。

### 2. 井底屁升

连续击中目标，用屁的反冲从井底向上飞。炸弹会伪装成普通目标，只留下一条很小的引线；误打会直接回到井底。

### 3. 屁力拔河

- 橙子：交替按 `Z` / `X`
- 蓝莓：交替按 `←` / `→`
- 炸弹出现后，下一位操作的玩家会被炸退完整绳长的 `1/5`，同时清空连击并扣 200 分

支持双人键盘、单人对机器人和机器人演示。

### 4. 节奏放屁

跟随原创高低音旋律，在音符落入狭窄判定区时按下对应按键：

- 橙子：`F` 低音 / `G` 高音
- 蓝莓：`J` 低音 / `K` 高音

按错音高、过早、过晚或漏按都会触发爆炸。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm ci
npm run dev
```

生产构建：

```bash
npm run build
```

## 技术栈

- React 19 + TypeScript
- Next.js / Vinext
- Web Audio API（屁声、爆炸声与节奏旋律）
- CSS 动画与响应式布局

## 项目状态

当前是可试玩 Demo，包含自动演示、本地双人键盘和人机模式。后续可以继续扩展更多简单键盘小游戏、地图机关和屁的运动方式。
